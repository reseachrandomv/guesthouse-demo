# Tharihiyaa — Island Guesthouse (demo)
A design demo for a fictional Maldivian guesthouse. The hero sky follows live Maldives time (UTC+5): dawn, day, sunset and night, with a preview toggle.
Plain HTML, CSS and JavaScript. Images are AI-generated; contacts are placeholders; rates are samples.
Design & build by [Fathimath Malaak Jaufar](https://reseachrandomv.github.io/cv/).
